## What you'll be able to do

- Set up a modern Python project with uv and write typed, tested code with Pydantic models and async HTTP calls.
- Call any web API safely, with secrets in environment variables, timeouts, retries and pagination.
- Build a small FastAPI service with validated request and response models and automatic docs.
- Use the shell, git, GitHub pull requests, Docker and GitHub Actions as part of a normal working day.
- Explain in plain words what a model, training, overfitting, an embedding and a transformer are.

## Before you start

You need to have written a little code in any language: variables, loops, functions and conditions. You do not need prior Python, math beyond school level or any machine learning background. If you have never programmed at all, take a beginner course first and come back. Read [how this guide works](#start) to plan your weekly hours.

## How to work through this level

Start with [Python for AI engineering](#l0-python-for-ai), because every other module uses it. Then take [Web APIs, HTTP and JSON](#l0-apis-and-http) and [Git, the command line and Docker](#l0-dev-tooling) in either order or side by side. [Just enough machine learning](#l0-ml-concepts) stands on its own and makes a good change of pace on evenings when you would rather watch and read than code.

Spend about a third of your time on resources and two thirds on practice. Use the "Start here" resources first and reach for "Go deeper" only where you feel shaky. Build [the project](#p0-api-service) in your final week, since it pulls the first three modules together. All four modules are core. If you already work as a developer, skim the Python and tooling modules, use their checklists to find gaps and put the saved time into the project.

## Milestone

You have finished Level 0 when a small, tested, containerized API service is on GitHub and you can explain the basic ideas behind the models you will use next.

- [ ] Your project repository has a README, a `.gitignore` that excludes secrets and at least one merged pull request.
- [ ] `uv run pytest` passes locally, and the same tests pass in GitHub Actions on every push.
- [ ] Your FastAPI service calls a public API with a timeout and retries and returns validated Pydantic models.
- [ ] One `docker run` command starts the service, and its interactive docs load at `/docs`.
- [ ] You can explain training vs inference, overfitting and embeddings without notes.
