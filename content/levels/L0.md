## What you'll be able to do

- Set up a modern Python project with uv and write typed, tested code with Pydantic models and async HTTP calls.
- Call any web API safely, with secrets in environment variables, timeouts, retries and pagination.
- Build a small FastAPI service with validated request and response models and automatic docs.
- Store and query data in SQLite with joins, groups, placeholders and transactions.
- Use the shell, git, GitHub pull requests, Docker and GitHub Actions as part of a normal working day.
- Explain in plain words what a model, training, overfitting, an embedding and a transformer are.

## Before you start

You should be able to write small programs on your own in any language, using variables, loops, functions and conditions, and fix your own errors by reading the message. You do not need prior Python, math beyond school level or any machine learning background. If you are newer to programming than that, take a beginner course such as Harvard's free CS50P first and come back. Read [how this guide works](#start) to plan your weekly hours.

## How to work through this level

Start with [Python for AI engineering](#l0-python-for-ai), because every other module uses it. Then take [Web APIs, HTTP and JSON](#l0-apis-and-http), [Just enough SQL](#l0-sql-basics) and [Git, the command line and Docker](#l0-dev-tooling) in any order or side by side. [Just enough machine learning](#l0-ml-concepts) stands on its own and makes a good change of pace on evenings when you would rather watch and read than code.

Spend about a third of your time on resources and two thirds on practice. Use the "Start here" resources first and reach for "Go deeper" only where you feel shaky. Build [the project](#p0-api-service) in your final week, since it pulls Python, web APIs and tooling together. All five modules are core. If you already write Python and use web APIs, SQL, git and Docker at work, choose the Fast track described in [how this guide works](#start). It skips those four modules and keeps the machine learning module and the project, which doubles as a placement check.

## Milestone

You have finished Level 0 when a small, tested, containerized API service is on GitHub and you can explain the basic ideas behind the models you will use next.

- [ ] Your project repository has a README, a `.gitignore` that excludes secrets and at least one merged pull request.
- [ ] `uv run pytest` passes locally, and the same tests pass in GitHub Actions on every push.
- [ ] Your FastAPI service calls a public API with a timeout and retries and returns validated Pydantic models.
- [ ] One `docker run` command starts the service, and its interactive docs load at `/docs`.
- [ ] You can explain training vs inference, overfitting and embeddings without notes.
