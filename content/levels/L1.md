## What you'll be able to do
- Explain tokens, next-token prediction, attention, sampling and hallucination in plain words.
- Call cloud and local models from Python with streaming, retries and per-call cost logging.
- Write, version and compare prompts that use roles, examples, delimiters and chaining.
- Turn messy text into validated JSON with schema-constrained output, Pydantic and capped retries.
- Measure output quality on a golden dataset and use the numbers to choose prompts and models.

## Before you start
You should be comfortable with Python functions, classes, virtual environments and JSON from [Python for AI engineering](#l0-python-for-ai), and with HTTP requests, status codes and API keys from [Web APIs, HTTP and JSON](#l0-apis-and-http). [Just enough machine learning](#l0-ml-concepts) gives you the intuition about training and embeddings that the first module builds on. Keep your work in Git, as covered in [Git, the command line and Docker](#l0-dev-tooling), because later levels reuse it.

## How to work through this level
Take the modules in order. [How LLMs work](#l1-how-llms-work) is mostly videos, so watch them while you set up API accounts. [Calling LLM APIs](#l1-llm-apis) and [Prompt engineering](#l1-prompt-engineering) are hands-on; build a small reusable client in the first and keep using it. In each module, do the Start here resources and the Practice first, and open Go deeper only where you feel shaky.

Start the [project](#p1-extraction-service) as soon as you finish [Structured outputs and function calling basics](#l1-structured-outputs), and build its golden set while you work through [Your first evals](#l1-first-evals). Plan on roughly half your time for resources and half for practice and the project. This level has no optional modules, because everything later depends on all five. If money is tight, use a free API tier or a local model through Ollama, which covers nearly every exercise.

## Milestone
You have finished this level when your extraction service runs end to end and its quality and cost are backed by measured numbers.
- [ ] You can explain, without notes, how a prompt becomes tokens, how the next token is chosen and why that leads to hallucinations.
- [ ] Your API client streams replies, retries rate-limit errors and logs tokens and cost for every call.
- [ ] Your extraction service returns validated JSON or a clear error for every document in your golden set.
- [ ] Your eval script reports field-level accuracy, cost per document and latency with one command.
- [ ] You have a results table comparing at least two prompt versions or models, with a written choice.
