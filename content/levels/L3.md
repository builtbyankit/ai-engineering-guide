## What you'll be able to do
- Design tools with clear descriptions, strict schemas, useful errors and safe side effects, and call them through more than one provider's API.
- Build an agent loop from scratch with stop conditions, step and cost budgets, and error recovery.
- Pick the simplest workflow or agent pattern for a task and back the choice with measurements.
- Build an MCP server, test it, and use it from an existing app and from your own agent.
- Manage context and memory so an agent stays accurate over long runs and across sessions.
- Ship a personal research agent that writes cited reports within a set budget.

## Before you start
You should be comfortable calling an LLM API from Python, including messages, streaming and token costs ([Calling LLM APIs](#l1-llm-apis)), and getting validated JSON back ([Structured outputs and function calling basics](#l1-structured-outputs)). Retrieval skills from [Embeddings and vector search](#l2-embeddings-vector-search) and [Building a RAG pipeline](#l2-rag-pipeline) help with memory and with citing sources. Bring the testing habit from [Your first evals](#l1-first-evals), because every module here asks you to compare designs with numbers. Memory stores and idempotent tools use SQLite, so revisit [Just enough SQL](#l0-sql-basics) if queries feel shaky.

## How to work through this level
Take the modules in order. Tool calling comes first because everything else depends on it, and the loop you write in the agent loop module becomes the core of the project. In each module, read the Start here resources, then spend most of your remaining time on the practice exercises, which are sized to become parts of the project. All five modules are core.

Start the [Personal research agent](#p3-research-agent) once your loop works, around the middle of the level, and add MCP and memory to it as you finish those modules. Avoid agent frameworks for now. [Level 4](#L4) introduces them, and they make far more sense after you have built the loop yourself.

## Milestone
You have finished this level when your research agent answers real questions within budget and you can explain every line of its loop.
- [ ] Your research agent, built without an agent framework, answers 10 test questions with cited reports and logs every step.
- [ ] Every run stops within its step and cost budget and records a stop reason.
- [ ] Your own MCP server works in the MCP Inspector, in one third-party host and in your agent.
- [ ] Your agent reuses memory of past research in a new session, and the run log shows it.
- [ ] You can explain, for one task you built, why you chose an agent over a workflow or the reverse.
