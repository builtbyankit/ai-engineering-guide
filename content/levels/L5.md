## What you'll be able to do

- Run error analysis on real agent traces and turn the failures you find into a prioritised eval suite.
- Build an LLM judge, calibrate it against your own labels and report how well it agrees with you.
- Evaluate agent trajectories and reliability with pass^k, and block regressions with an eval gate in CI.
- Trace every model and tool call with OpenTelemetry-style spans and watch cost, latency and user feedback on a dashboard.
- Threat-model an agent against prompt injection and the lethal trifecta, apply structural defences and red-team the result.
- Read agent benchmark claims critically, if you take the optional module.

## Before you start

You need a working agent with tools to measure and attack. Finish [Level 3](#L3), especially [The agent loop](#l3-agent-loop) and [Tool calling in depth](#l3-tool-calling), and ideally [Level 4](#L4) with [Human in the loop](#l4-human-in-the-loop). This level assumes you can already build a small golden dataset and run assertion checks, so revisit [Your first evals](#l1-first-evals) and [Evaluating RAG](#l2-rag-evaluation) if that feels shaky. Basic GitHub Actions from [Git, the command line and Docker](#l0-dev-tooling) will help with the CI gate.

## How to work through this level

Start with [Evals in depth](#l5-evals-in-depth), because error analysis gives you the vocabulary for everything else. Take [Observability and tracing](#l5-observability) next or in parallel, since traces make error analysis much faster. Finish with [Security and guardrails](#l5-security), which reuses your eval suite for injection regression tests. Split your time roughly into thirds: resources, practice exercises and the project.

At 10 to 12 hours a week the three core modules take about 2.5 to 3 weeks and the project 1.5 to 2 weeks. Much of the module practice feeds straight into the project, so you may finish nearer the low end of the 4 to 5 weeks shown above. [Reading agent benchmarks](#l5-benchmarks) is optional and suits you if you choose models for a team, write about AI or plan to publish evals. Build everything on your own agent from [Level 3](#L3) or [Level 4](#L4), so the work carries into [Level 6](#L6) and [the capstone](#capstone).

## Milestone

Your agent is measured, observable and hardened, and you have the evidence to show it.

- [ ] A versioned eval suite, built from error analysis, runs in CI and fails the build on a regression.
- [ ] Your LLM judge reports TPR and TNR on a held-out labelled set.
- [ ] Every agent run produces a trace with model and tool spans, and a dashboard shows cost per task and p95 latency.
- [ ] A prompt-injection suite of at least 20 cases runs against your agent, with attack success rates before and after your fixes.
- [ ] Your README contains a threat model naming which leg of the lethal trifecta you removed or gated.
