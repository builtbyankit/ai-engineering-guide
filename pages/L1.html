What you'll be able to do

  • Explain tokens, next-token prediction, attention, sampling and hallucination in plain words.
  • Call cloud and local models from Python with streaming, retries and per-call cost logging.
  • Write, version and compare prompts that use roles, examples, delimiters and chaining.
  • Turn messy text into validated JSON with schema-constrained output, Pydantic and capped retries.
  • Measure output quality on a golden dataset and use the numbers to choose prompts and models.

Before you start

You should be comfortable with Python functions, classes, virtual environments and JSON from Python for AI engineering, and with HTTP requests, status codes and API keys from Web APIs, HTTP and JSON. Just enough machine learning gives you the intuition about training and embeddings that the first module builds on. Keep your work in Git, as covered in Git, the command line and Docker, because later levels reuse it.

How to work through this level

Take the modules in order. How LLMs work is mostly videos, so watch them while you set up API accounts. Calling LLM APIs and Prompt engineering are hands-on; build a small reusable client in the first and keep using it. In each module, do the Start here resources and the Practice first, and open Go deeper only where you feel shaky.

Start the project as soon as you finish Structured outputs and function calling basics, and build its golden set while you work through Your first evals. Plan on roughly half your time for resources and half for practice and the project. This level has no optional modules, because everything later depends on all five. If money is tight, use a free API tier or a local model through Ollama, which covers nearly every exercise.
