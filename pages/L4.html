Frameworks and multi-agent systems

Build stateful, resumable agents with LangGraph or an agent SDK, use multiple agents only when they pay off, and keep humans in charge of risky actions.

Pages done 0/0 · Milestone 0/5 · Must-ship tasks 0/0

What you'll be able to do

  • Build agents as graphs with typed state, checkpoints, interrupts and streaming in LangGraph.
  • Compare the major agent SDKs on concrete criteria and build the same agent in two of them.
  • Choose between single-agent and multi-agent designs using your own measurements of accuracy and token cost.
  • Pause risky actions for human approval, resume durable runs after a restart, and keep an audit trail.
  • Ship a support triage workflow that classifies, researches and drafts, then waits for a person before anything is sent.

Before you start

Finish Level 3 first, especially The agent loop, Workflows and agent design patterns and Memory and context engineering. You should have built a tool-calling agent by hand, because that is how you will see what a framework does for you. The project also searches a knowledge base, so review Building a RAG pipeline, and be comfortable with async code and Pydantic from Python for AI engineering.

How to work through this level

Start with Stateful agents with LangGraph, because state, checkpoints and interrupts come up again in every later module. Then work through Agent SDKs compared, Multi-agent systems and Human in the loop in that order. Spend about a third of each module's hours on resources and the rest on practice. Start the project once Human in the loop is done, around week 3, and give it two full weeks.

Two optional specialisations add about one week each, and both are easier after the core modules. Take Coding agents if you want to build or customise agents that read, edit and test code. Take Browser and computer-use agents if your agents must operate websites or desktop apps that have no API.
