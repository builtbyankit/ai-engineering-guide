What you'll be able to do

  • Run error analysis on real agent traces and turn the failures you find into a prioritised eval suite.
  • Build an LLM judge, calibrate it against your own labels and report how well it agrees with you.
  • Evaluate agent trajectories and reliability with pass^k, and block regressions with an eval gate in CI.
  • Trace every model and tool call with OpenTelemetry-style spans and watch cost, latency and user feedback on a dashboard.
  • Threat-model an agent against prompt injection and the lethal trifecta, apply structural defences and red-team the result.
  • Read agent benchmark claims critically, if you take the optional module.

Before you start

You need a working agent with tools to measure and attack. Finish Level 3, especially The agent loop and Tool calling in depth, and ideally Level 4 with Human in the loop. This level assumes you can already build a small golden dataset and run assertion checks, so revisit Your first evals and Evaluating RAG if that feels shaky. Basic GitHub Actions from Git, the command line and Docker will help with the CI gate.

How to work through this level

Start with Evals in depth, because error analysis gives you the vocabulary for everything else. Take Observability and tracing next or in parallel, since traces make error analysis much faster. Finish with Security and guardrails, which reuses your eval suite for injection regression tests. Split your time roughly into thirds: resources, practice exercises and the project.

At 10 to 12 hours a week the three core modules take about 2.5 to 3 weeks and the project 1.5 to 2 weeks. Much of the module practice feeds straight into the project, so you may finish nearer the low end of the 4 to 5 weeks shown above. Reading agent benchmarks is optional and suits you if you choose models for a team, write about AI or plan to publish evals. Build everything on your own agent from Level 3 or Level 4, so the work carries into Level 6 and the capstone.
